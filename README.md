# VendiSmart Managed Solutions

A high-tech, modern web application for **VendiSmart** - UK's leading smart vending machine service provider for corporate offices, universities, and commercial spaces.

## 🚀 Overview

VendiSmart delivers zero-hassle, fully managed smart vending solutions featuring cash-free touchless payments, real-time inventory telemetry, and premium fresh refreshments.

## 📄 Pages Included

- **Home (`index.html`)**: Interactive landing page with feature showcase, trust badges, and CTA.
- **How It Works (`how-it-works.html`)**: Step-by-step telemetry, delivery, restocking, and telemetry workflow.
- **Benefits (`benefits.html`)**: Venue vs VendiSmart comparison matrix and core advantages.
- **Locations (`locations.html`)**: Suitable UK venues including offices, universities, and logistics hubs.
- **About Us (`about.html`)**: Mission, IoT technology, and company values.
- **Request a Machine (`request-a-machine.html`)**: Multi-step inquiry form for zero-cost machine installation.
- **Contact (`contact.html`)**: Sales, support, and office location details.
- **FAQs (`faqs.html`)**: Comprehensive answer center.
- **Legal**: `terms.html`, `privacy.html`, and `cookie-policy.html`.

## 🛠️ Tech Stack & Design System

- **HTML5 & CSS**: Clean semantic markup styled with Tailwind CSS & Google Material Symbols.
- **Typography**: Plus Jakarta Sans (Headings) & Inter (Body).
- **Theme**: Charcoal Navy, Electric Indigo (`#673DE6`), Cyan Tech (`#00D1FF`), and Glassmorphism elevation.

## 🏃 Local Development

Simply open `index.html` in any browser, or launch a local server:

```bash
npm run dev
```
